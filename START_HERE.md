# 🚀 Quick Start: Agent Genesis Kit

Welcome! You are just 3 minutes away from transforming your standard AI assistant into a tailored, persistent, high-performance engineering partner powered by the **Jarvis** architecture.

---

### Option A: The Zero-Terminal Chat Prompt (Easiest)
Just open the AI chat in any workspace and paste:
```text
Clone https://github.com/xvacorx/agent-genesis-kit (or download it if git is not installed) and run the /setup interactive onboarding wizard to configure my custom agent.
```

---

### Option B: The 1-Line Terminal Magic
Run this in your terminal to instantly set up the folder:
- **Windows (PowerShell):** `irm https://raw.githubusercontent.com/xvacorx/agent-genesis-kit/main/install.ps1 | iex`
- **macOS / Linux:** `curl -fsSL https://raw.githubusercontent.com/xvacorx/agent-genesis-kit/main/install.sh | bash`

---

### Option C: Classic Git Clone or Download
1. Open this `agent-genesis-kit` folder inside **Antigravity IDE**, **Claude Code**, or **Cursor**.
2. Simply open the AI chat and send:
```text
/setup
```
*(You can speak in ANY language of the world — your assistant detects and adapts to you automatically)*.

---

### Step 3: Interactive Genesis Interview
Your AI will wake up and guide you through an interactive, step-by-step onboarding:

1. **Identity & Vibe:** Choose your assistant's name, personality, and communication style.
2. **Your Profile & Hardware:** Set your developer persona, operating system, and whether you work on a single PC or synchronize across machines.
3. **Storage & Cloud Topology:** Configure local-only mode or learn best practices for cloud sync (Google Drive, OneDrive, Nextcloud, GitHub).
4. **Skills & Superpowers:**
   - **Graphify (Activated by default):** Navigate complex repos as knowledge graphs and save up to 80% tokens.
   - **900+ Skills Vault & Dynamic Profiles:** Choose an initial profile (`gamedev`, `web`, `devops`, `all-in-one`, `core`) or manage them via `python skills_manager.py`.
   - **74 World-Class Brand Design Systems:** Access design tokens and aesthetic DNA from Apple, Stripe, Linear, Tesla, Vercel, and more (`design-md-library/`).
   - **Core Safeguards:** Anti-slop filters, root-cause debugging, and auto-improving memory.
5. **Evolutionary Merge:** Your agent will safely install all rules, memory systems, and tools without touching or breaking any of your existing projects.
