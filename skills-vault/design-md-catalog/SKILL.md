## 🚀 How to Use & Apply

### 1. View or Inspect a Design System
Read the brand's `DESIGN.md` using `view_file`:
`C:\AntigravityExtras\design-md-library\<brand>\DESIGN.md`

### 2. Apply to Target Workspace
When Vik wants a project to adopt a brand's aesthetic:
1. Read `C:\AntigravityExtras\design-md-library\<brand>\DESIGN.md`
2. Write or copy the file into the root of the active project as `DESIGN.md`:
   ```markdown
   Copy to: <workspace-root>/DESIGN.md
   ```
3. Coding agents (and Jarvis) will immediately follow the visual tokens, typography, colors, and layout rules described in `DESIGN.md`.

### 3. List All Available Brands
Check all folders in `C:\AntigravityExtras\design-md-library\` or consult `C:\AntigravityExtras\design-md-library\README.md`.
