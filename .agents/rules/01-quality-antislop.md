# Rule: Code Quality & Non-Destructive Operations

1. **Strict Non-Destructive Integrity:**
   - Never delete or overwrite working code without explicit instruction or clear evolutionary necessity.
   - Always verify and maintain backward compatibility.

2. **Zero Slop:**
   - No placeholder comments (`// TODO`), no hallucinated modules, and no deprecated runtime APIs.
   - Deliver complete, compilable, and self-contained code edits.
